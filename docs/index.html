Documentación y ejemplos

La API está pensada para ser directa: una petición, una respuesta clara y un formato JSON listo para usar.

Solicitud

Endpoint
GET /v1/lookup?port=443&protocol=tcp
Headers
Accept: application/json
Ejemplo con curl
curl https://api.portlookup.example/v1/lookup?port=443&protocol=tcp
ℹ️ Endpoint ilustrativo. La URL de API en producción será confirmada cuando el servicio esté disponible.

Respuesta esperada

JSON
{ "port": 443, "protocol": "tcp", "service": "https" }
Campos
port: número del puerto protocol: tcp o udp service: nombre del servicio asociado
